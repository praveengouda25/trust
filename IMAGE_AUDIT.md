# SVRST Trust image audit

All website photography is sourced from the supplied local assets. No AI,
Unsplash, Pexels, or generated image source is used.

| Asset group | Intended purpose | Website usage |
| --- | --- | --- |
| `hero-education`, `education-classroom`, `education-reading`, `mentoring` | Education and learning support | Home hero, education programme, stories |
| `hero-healthcare`, `health-checkup`, `health-awareness` | Health camps and awareness | Home hero, healthcare programme |
| `hero-food`, `food-distribution`, `food-kitchen` | Food support and meals | Home hero, food-support programme |
| `hero-women`, `women-digital`, `women-enterprise` | Women’s skills and livelihood work | Home hero, women-empowerment programme |
| `event-kits`, `event-walk`, `volunteers` | Events and volunteering | Events, membership, corporate partnership, volunteer page |
| `community`, `team-lead`, `achievements` | Organisation/community context | About, journey, team, achievements |
| `story-student`, `story-family` | Respectful anonymised stories | Homepage stories |
| `donate-bg` | Donation page presentation | Donation page |
| `public/gallery/*.jpg` | Supplied SVRST gallery export | Events gallery only |

The gallery page uses a distinct set of 12 photographs copied from the
supplied `svrst_Gallery` folder. Gallery captions remain generic because the
export does not provide verified event/category metadata; this avoids
inventing context for a photograph.
